# Tampermonkey Scripts

个人维护的油猴脚本，每个脚本使用独立目录管理。

| 脚本 | 用途 | 文件 |
| --- | --- | --- |
| [系统测试填表助手](form-assistant/README.md) | 自动识别表单、生成测试数据、保存和回填模板 | [form-assistant.user.js](form-assistant/form-assistant.user.js) |
| V2EX 纯净阅读助手 | 帖子纯净阅读、分页合并、删除回复和复制 | [default.js](v2ex-pure-read/default.js) |

系统测试填表助手可直接从文件导入 Tampermonkey，安装及使用方法见对应目录的说明。
