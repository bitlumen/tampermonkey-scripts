# Tampermonkey Scripts

个人维护的油猴脚本，每个脚本使用独立目录管理。

| 脚本                                          | 用途                                       | 文件                                                            |
|-----------------------------------------------|--------------------------------------------|-----------------------------------------------------------------|
| [系统测试填表助手](form-assistant/README.md)  | 整表重填、全局单项随机、生成偏好和模板回填 | [form-assistant.user.js](form-assistant/form-assistant.user.js) |
| [V2EX 纯净阅读助手](v2ex-pure-read/README.md) | 帖子纯净阅读、分页合并、回复移除恢复和复制 | [v2ex-pure-read.user.js](v2ex-pure-read/v2ex-pure-read.user.js) |

各脚本均可直接从文件导入 Tampermonkey，安装及使用方法见对应目录的说明。
