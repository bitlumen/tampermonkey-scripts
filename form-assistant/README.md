# 系统测试填表助手

版本：**1.0.0**

用于测试网页表单的 Tampermonkey 脚本。自动识别当前填写区域，支持一键填空、单项随机、生成偏好、文本库和表单模板。

## 安装

1. 打开 Tampermonkey 管理面板，进入“实用工具”。
2. 使用“从文件导入”，选择本目录的 [form-assistant.user.js](form-assistant.user.js)，确认安装。
3. 刷新需要填写的页面。右下角显示星形入口，鼠标悬停或键盘聚焦时展开“填表助手”；触屏可直接点击图标。

脚本是可独立导入的单个文件，无需构建或安装 Node.js。

默认在本地和局域网地址显示入口，包括 `localhost`、回环地址、私网 IPv4、IPv6 私有及链路本地地址，以及短主机名、`.local`、`.lan`、`.home.arpa`。
其他网站可在油猴菜单中选择“本站开启助手”。“本站隐藏助手”和“本站恢复默认”按协议、主机及端口记忆，同站不同路径共用设置。

## 日常填写

1. 打开“填表助手”，查看当前可填写项数。
2. 点击“一键填空”。默认保留已有内容，勾选“覆盖已有内容”后可替换非空项。
3. 在“填写记录”中检查结果，同时查看网页自身的校验提示。
4. “停止”结束后续填写；“恢复本次”尝试恢复最近一轮本地改动，之后被手动修改的值不会被覆盖。

脚本优先处理最上层可见弹窗或抽屉，其次是当前页签或主内容区中的填写表单。最上层弹窗没有可填写项时，不会填写后面的表单。搜索、查询、筛选和导航中的控件会被排除。动态增加字段后，可使用面板右上角的刷新按钮重新识别；单次最多识别 500 项。

脚本不会点击业务提交按钮。填写会触发网页输入及联动事件，因此网页自身的自动保存仍可能发生。“恢复本次”不能撤回后台保存，切换页面、表单或刷新后也不能恢复此前的改动。

## 单项随机与单项设置

开启面板顶部的“单项随机”后，字段旁显示骰子按钮：左键随机填写该字段，右键打开单项设置。面板收起后骰子仍可使用，刷新页面后此开关默认关闭。

单项操作会替换该字段已有内容，不受“覆盖已有内容”限制。被面板遮挡、只读、禁用、敏感、未适配或有歧义的字段不显示骰子。

“单项设置”支持按页面设置生成、数字随机、文字随机、固定值和跳过。点击“保存单项设置”保存规则；“定位”会滚动并标出字段，“换此项”立即生成一个值。

- 固定值支持 `{date}`、`{seed}`、`{timestamp}`。
- 下拉和单选填写选项文字，多选以逗号分隔，开关填写 `true` 或 `false`。
- 未勾选的复选框、关闭的开关视为空值；需要保持不变时，设置为“跳过”。

## 生成偏好

“生成偏好”默认展开，按当前页面及表单保存。点击“保存生成偏好”或直接填写即可保存配置。

数字支持自动、仅整数和允许小数，可指定包含两端的范围及最多小数位（0～6）。生成结果同时遵守网页的 `min`、`max`、`step`，冲突时保留原值并提示。原生 `number` 未声明 `step` 时步长默认为 1；允许小数不保证每次生成小数，也不强制保留尾部 0。

普通文字有四种来源：

| 来源 | 行为 |
| --- | --- |
| 内置文本库 | 从 1056 个词组和常用单字片段中混合抽取、拼接 |
| 自定义文本库 | 从保存的整段文字中抽取片段并拼接 |
| 自定义候选文案 | 每行一条；未设字数时尽量保留整条 |
| 在线短句 | 主动选择后请求一言公共接口，按需要截取或重复 |

普通文字不按姓名、企业等标签添加固定前后缀。邮箱、手机号、网址和邮编等可识别格式字段按格式生成，不受普通文本库和随机字数设置影响；格式与网页长度限制冲突时保留原值，可改用固定值。

最小字数和最大字数支持 0～10000 的整数，并受网页 `minlength`、`maxlength`、`required` 进一步限制：

- 都留空时，内置和自定义文本库的单行默认生成 20～60 字，多行默认生成 100～300 字。
- 两端都填写时，在范围内随机；两端相同即固定长度。
- 只填最小值时，单行用 40、多行用 200 的跨度补足上限，且不低于默认上限。
- 只填最大值时，通常从 1 到该上限随机；最大值为 0 时可生成空值。
- 计数与网页长度一致：汉字、字母和标点通常计 1，部分表情计 2，截取不会拆开单个 Unicode 字符。无法满足限制时保留原值。

“复现相同数据”支持编辑数据标记或“换一组”。相同标记用于复现同一结构下的普通随机数据；日期、在线短句、变化的下拉选项及 `{timestamp}` 不保证跨时间一致，精确复现可保存模板。

## 我的文本库

在“生成偏好”中选择“自定义文本库”，再打开“粘贴文字 / 导入 TXT”，或直接展开“我的文本库”。粘贴文字或导入 `.txt` 后点击“保存文本库”。保存生成偏好或直接填表也会保存编辑中的内容。

- TXT 文件最大 1 MB，文本最多 500000 字；支持 UTF-8、带 BOM 的 UTF-16 LE/BE、GBK/GB18030。
- 导入会替换编辑区草稿，保存后生效；无效或超限文件保留原文，读取期间继续编辑时保留新输入。
- 文本拆成最多 24 个 Unicode 字符的片段，随机抽取时保留标点、压缩空白。
- 文本库保存在本机油猴中，各页面共用；其他已打开标签页刷新后读取更新。
- 仅选择“自定义文本库”时才使用，不会混入内置库，也不会发送给在线接口。
- 模板导出不包含文本库，请保留 TXT 文件作为备份。

## 我的模板

“我的模板”默认收起，点击标题展开。折叠不会清空已选模板或名称草稿。

1. 填好表单后，填写或使用自动建议的模板名称，点击“存为模板”。
2. 选择已保存的模板，点击“回填到表单”。需要替换非空项时勾选“覆盖已有内容”。
3. 选择“显示本站其他页面模板”，可以使用同站其他路径的模板。

模板按网站（协议、主机、端口）和路径区分，支持 `#/` 路由，普通查询参数不区分页面。字段按稳定标识、标签和分组匹配，歧义或缺失选项会提示。搜索、跳过和敏感字段不会保存；模板保存固定内容，不受后续随机字数设置影响。保存当前页面的同名模板前会询问是否覆盖。

## 模板备份与跨环境导入

在“备份与更多”中导出本站模板或导入 JSON。备份包含字段值，不包含字段规则、生成偏好、自定义文本库和网站显示设置。导入会添加独立模板，不覆盖已有模板。

测试环境和正式环境复用模板时：

1. 在来源网站导出模板。
2. 在目标网站打开“备份与更多”，勾选“导入到当前网站”，再导入 JSON。
3. 页面路径一致时可直接选择回填；路径不同时，勾选“显示本站其他页面模板”。

导入后的副本归属目标网站，保留页面路径和字段信息，来源模板不变。文件名中的域名只是来源标记，无需修改。未勾选“导入到当前网站”时，模板保留 JSON 中的网站归属，外站模板不会出现在当前网站列表中。

## 支持范围与数据存储

支持原生输入、数字、邮箱、电话、日期、单选、复选、下拉，以及 React / Vue 页面、Element Plus / Ant Design 的常见输入、开关、普通下拉和多选，支持简单联动及动态字段。

组件日历、日期范围、级联、树选择、富文本、文件、复杂远程选项、虚拟列表、iframe、封闭 Shadow DOM 和画布控件可能需要手动操作或单独适配。密码、验证码、密钥、证件、银行卡等敏感或认证字段默认跳过。

数据通过 `GM_getValue` / `GM_setValue` 保存于本机 Tampermonkey，菜单使用 `GM_registerMenuCommand` 注册。普通模式无需网络，也不依赖第三方脚本库。

在线短句模式请求 `https://v1.hitokoto.cn/`，不附带表单内容或 Cookie，可能携带浏览器 Origin。每批最多请求 5 句后复用，失败或超时保留字段原值。

## 开发维护

直接编辑 [form-assistant.user.js](form-assistant.user.js)。发布时同步更新脚本头的 `@version`、代码中的 `VERSION` 和本说明的版本号，再从文件导入 Tampermonkey。

可在仓库根目录执行语法检查：

```sh
node --check form-assistant/form-assistant.user.js
```
