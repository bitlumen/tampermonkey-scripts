# 系统测试填表助手

版本：**1.3.1**

用于测试网页表单的 Tampermonkey 脚本。自动识别当前填写区域，提供“整表重填 / 填表设置 / 单项随机”三段快捷条，支持生成偏好、文本库和表单模板。

## 安装

1. 打开 Tampermonkey 管理面板，进入“实用工具”。
2. 使用“从文件导入”，选择本目录的 [form-assistant.user.js](form-assistant.user.js)，确认安装。
3. 刷新需要填写的页面。右下角显示星形入口，鼠标悬停、键盘聚焦或点击图标可展开三段快捷条；触屏可直接轻触图标。

脚本是可独立导入的单个文件，无需构建或安装 Node.js。

默认在本地和局域网地址显示入口，包括 `localhost`、回环地址、私网 IPv4、IPv6 私有及链路本地地址，以及短主机名、`.local`、`.lan`、`.home.arpa`。
其他网站可在油猴菜单中选择“本站开启助手”。“本站隐藏助手”和“本站恢复默认”按协议、主机及端口记忆，同站不同路径共用设置。

## 日常填写

| 入口 | 功能 |
|------|------|
| 整表重填 | 按当前规则重新生成并覆盖当前表单，每次点击使用新一组随机数据 |
| 填表设置 | 打开或收起设置面板，调整生成偏好、单项规则、文本库及模板 |
| 单项随机 | 开关字段旁的骰子按钮，选择在本机油猴中全局记忆 |

星形入口只负责展开快捷条，不会触发填表。设置面板打开或正在填写时，快捷条保持展开。

“整表重填”不受面板内“覆盖已有内容”限制，但仍遵守固定值、跳过和字段限制。随机值会尽量与当前值不同；复选和开关会切换状态；固定值或只有一个合法结果的字段可能保持原值。

执行中首段变为“停止填写”，再次点击可停止后续填写。完成或停止后，可在提示中点击“恢复本次”，尝试恢复最近一轮本地改动，之后被手动修改的值不会被覆盖。

需要保留已有内容时，打开“填表设置”使用“一键填空”。它默认只填空项，勾选“覆盖已有内容”后可替换非空项。在“填写记录”中检查结果，同时查看网页自身的校验提示。

脚本优先处理最上层可见弹窗或抽屉，其次是当前页签或主内容区中的填写表单。最上层弹窗没有可填写项时，不会填写后面的表单。搜索、查询、筛选和导航中的控件会被排除。动态增加字段后，可使用面板右上角的刷新按钮重新识别；单次最多识别 500 项。

脚本不会点击业务提交按钮。填写会触发网页输入及联动事件，因此网页自身的自动保存仍可能发生。“恢复本次”不能撤回后台保存，切换页面、表单或刷新后也不能恢复此前的改动。

## 单项随机与单项设置

开启快捷条的“单项随机”后，字段旁显示骰子按钮：左键随机填写该字段，右键打开单项设置。面板收起后骰子仍可使用。

该开关首次安装默认关闭。选择保存在当前浏览器配置中的同一份油猴脚本内，各网站共用，刷新页面、新开标签页和重启浏览器后仍保留，已打开的标签页同步更新。隐藏某个网站的助手不会关闭全局开关。切换开关不会填写表单，也不会提交或清空面板中尚未保存的设置。

单项操作会替换该字段已有内容，不受“覆盖已有内容”限制。被面板遮挡、只读、禁用、敏感、未适配或有歧义的字段不显示骰子。

“单项设置”支持按页面设置生成、数字随机、文字随机、固定值和跳过。点击“保存单项设置”保存规则；“定位”会滚动并标出字段，“换此项”立即生成一个值。

- 固定值支持 `{date}`、`{seed}`、`{timestamp}`。
- 下拉和单选填写选项文字，多选以逗号分隔，开关填写 `true` 或 `false`。
- 日期组件按页面显示格式填写，例如 `2026-10-29`、`2026`、`14:30:00`。日期范围填写 `2026-10-01,2026-10-31`，起止值用逗号分隔。
- 级联和树选择可填写唯一的末级名称，重名时用完整路径，例如 `四川省 / 成都市 / 锦江区`；多条路径用逗号分隔。
- 未勾选的复选框、关闭的开关视为空值；需要保持不变时，设置为“跳过”。

## 字段识别与已有数据兼容

字段名称优先取关联的 `label`、ARIA 名称、常见表单组件标签和表格列标题；自定义布局会补充读取最近的单控件容器中的相邻标签。还会识别字段集、分组和相邻章节标题。推断附近标签时，会排除多个控件共用的行标题、隐藏文字、帮助和报错文字。placeholder 只是最后的名称兜底，不是控件的唯一标识。

整表填写、单项随机、定位和恢复使用当前页面中的实际控件区分字段，相同 placeholder 的多个输入框可以独立操作。页面替换控件节点后，只在标签、分组或稳定标识能唯一对应时继续；原控件用途改变或仍有歧义时跳过，不按页面顺序猜测。

整表自动生成有一项联动处理：助手成功改变单选、下拉、开关等选择控件后，如果页面复用尚未填写的输入框并改变标签或单位，会重新识别这些字段，按新含义生成数据。仅对前后都能唯一识别、且都使用“按页面设置生成”的字段生效；固定值、单项数字/文字规则、跳过规则及模板值不会自动迁移到新单位。生成期间发生的其他用途变化仍会停止该项写入。

跨刷新保存的单项规则和模板仍使用稳定字段特征。完全同名且没有可区分特征，或完全缺少名称和标识的字段，单项规则仅在当前控件上生效，重绘或刷新后需重设；这类字段不会写入新模板，保存时会提示。框架自动生成的 ID 不作为可靠的长期标识。

已有规则、生成偏好和模板继续读取原存储格式，不需要清空油猴数据。旧名称或旧标识能唯一匹配时继续使用，保存规则时补充新的字段特征；原有条目保留。旧规则冲突或无法定位时会提示，存在规则冲突的字段暂不填写，可在“单项设置”中明确选择新规则或“按页面设置生成”。旧模板遇到歧义也会跳过对应项。

部分旧规则只保存了字段特征的散列值。如果其原始自动 ID 已变化，且没有足够信息恢复对应关系，脚本会保留规则并提示重新指定，不会把它套到其他字段。

## 生成偏好

“生成偏好”默认展开，按当前页面及表单保存。点击“保存生成偏好”或直接填写即可保存配置。

数字支持自动、仅整数和允许小数，可指定包含两端的范围及最多小数位（0～6）。生成结果同时遵守网页的 `min`、`max`、`step`，冲突时保留原值并提示。原生 `number` 未声明 `step` 时步长默认为 1；允许小数不保证每次生成小数，也不强制保留尾部 0。

数字控件自动补零（如 `12.34` 显示为 `12.3400`）按相同数值核对，不会误报写入失败；清空、舍入或改成其他数值仍会提示。

普通文字有四种来源：

| 来源           | 行为                                         |
|----------------|----------------------------------------------|
| 内置文本库     | 从 1056 个词组和常用单字片段中混合抽取、拼接 |
| 自定义文本库   | 从保存的整段文字中抽取片段并拼接             |
| 自定义候选文案 | 每行一条；未设字数时尽量保留整条             |
| 在线短句       | 主动选择后请求一言公共接口，按需要截取或重复 |

普通文字不按姓名、企业等标签添加固定前后缀。邮箱、手机号、网址和邮编等可识别格式字段按格式生成，不受普通文本库和随机字数设置影响；格式与网页长度限制冲突时保留原值，可改用固定值。

最小字数和最大字数支持 0～10000 的整数，并受网页 `minlength`、`maxlength`、`required` 进一步限制：

- 都留空时，内置和自定义文本库的单行默认生成 20～60 字，多行默认生成 100～300 字。
- 两端都填写时，在范围内随机；两端相同即固定长度。
- 只填最小值时，单行用 40、多行用 200 的跨度补足上限，且不低于默认上限。
- 只填最大值时，通常从 1 到该上限随机；最大值为 0 时可生成空值。
- 计数与网页长度一致：汉字、字母和标点通常计 1，部分表情计 2，截取不会拆开单个 Unicode 字符。无法满足限制时保留原值。

“复现相同数据”支持编辑数据标记或“换一组”。相同标记用于复现同一结构下的普通随机数据；日期、在线短句、变化的下拉选项及 `{timestamp}` 不保证跨时间一致，精确复现可保存模板。

面板内“一键填空”使用此标记。“整表重填”和单项随机每次使用新的随机批次，不会修改面板中的标记。

## 我的文本库

在“生成偏好”中选择“自定义文本库”，再打开“粘贴文字 / 导入 TXT”，或直接展开“我的文本库”。粘贴文字或导入 `.txt` 后点击“保存文本库”。保存生成偏好或直接填表也会保存编辑中的内容。

- TXT 文件最大 1 MB，文本最多 500000 字；支持 UTF-8、带 BOM 的 UTF-16 LE/BE、GBK/GB18030。
- 导入会替换编辑区草稿，保存后生效；无效或超限文件保留原文，读取期间继续编辑时保留新输入。
- 文本拆成最多 24 个 Unicode 字符的片段，随机抽取时保留标点、压缩空白。
- 文本库保存在本机油猴中，各页面共用；其他已打开标签页刷新后读取更新。
- 仅选择“自定义文本库”时才使用，不会混入内置库，也不会发送给在线接口。
- 模板导出不包含文本库，请保留 TXT 文件作为备份。

## 我的模板

“我的模板”默认收起，点击标题展开。折叠不会清空已选模板或名称草稿。

1. 填好表单后，填写或使用自动建议的模板名称，点击“存为模板”。
2. 选择已保存的模板，点击“回填到表单”。需要替换非空项时勾选“覆盖已有内容”。
3. 选择“显示本站其他页面模板”，可以使用同站其他路径的模板。

模板按网站（协议、主机、端口）和路径区分，支持 `#/` 路由，普通查询参数不区分页面。字段按稳定标识、标签和分组匹配，歧义或缺失选项会提示。搜索、跳过、敏感和无法区分的同名字段不会保存；模板保存固定内容，不受后续随机字数设置影响。保存当前页面的同名模板前会询问是否覆盖。

## 模板备份与跨环境导入

在“备份与更多”中导出本站模板或导入 JSON。备份包含字段值，不包含字段规则、生成偏好、自定义文本库、单项随机开关和网站显示设置。导入会添加独立模板，不覆盖已有模板。

测试环境和正式环境复用模板时：

1. 在来源网站导出模板。
2. 在目标网站打开“备份与更多”，勾选“导入到当前网站”，再导入 JSON。
3. 页面路径一致时可直接选择回填；路径不同时，勾选“显示本站其他页面模板”。

导入后的副本归属目标网站，保留页面路径和字段信息，来源模板不变。文件名中的域名只是来源标记，无需修改。未勾选“导入到当前网站”时，模板保留 JSON 中的网站归属，外站模板不会出现在当前网站列表中。

## 支持范围与数据存储

支持原生输入、数字、邮箱、电话、日期、单选、复选、下拉，以及 React / Vue 页面、Element Plus / Ant Design 的常见输入、开关、普通下拉和多选，支持简单联动及动态字段。

**日期组件**：支持 Ant Design 和 Element Plus 的日期、年份、月份、日期范围、日期时间、日期时间范围、时间。自动生成通过日历和时间面板选择可用值，遵守禁用项；固定值和模板通过组件输入、确认流程提交。仅禁止手动键入、仍能打开选择面板的输入框也可处理。选择面板内的输入框不会被重复识别为表单字段。

**级联和树选择**：支持上述两个组件库的常见单选、多选，逐层展开并等待下级选项加载，默认选择可用的末级节点。会核对完整路径和选中结果，不会仅凭重名的末级文字猜测。自动生成、固定值、模板回填和“恢复本次”共用适配逻辑；从空值恢复时通过组件清空按钮操作。

适配以页面公开的 DOM 和交互事件为依据，不读写框架私有状态。加载等待每步最多 3 秒，层级最多 16 层，遍历最多 300 个节点；超时、同层重名、找不到清空按钮或无法核对显示格式时会记录具体原因。日期随机值从当前日历可选范围中选取。自定义显示内容、折叠选中标签、虚拟滚动、超大或需输入关键词才能加载的树可能需要单独适配；不能保证任意组件库或自定义控件都适用。恢复也受当前选项、禁用规则和可清空设置限制。

文件仍需手动选择。富文本、未适配组件、复杂远程选项、iframe、封闭 Shadow DOM 和画布控件可能需要手动操作或单独适配。密码、验证码、密钥、证件、银行卡等敏感或认证字段默认跳过。

数据通过 `GM_getValue` / `GM_setValue` 保存于本机 Tampermonkey，单项随机开关使用 `GM_addValueChangeListener` 在标签页间同步，菜单使用 `GM_registerMenuCommand` 注册。普通模式无需网络，也不依赖第三方脚本库。

在线短句模式请求 `https://v1.hitokoto.cn/`，不附带表单内容或 Cookie，可能携带浏览器 Origin。每批最多请求 5 句后复用，失败或超时保留字段原值。

## 开发维护

直接编辑 [form-assistant.user.js](form-assistant.user.js)。发布时同步更新脚本头的 `@version`、代码中的 `VERSION`、`package.json` / `package-lock.json` 和本说明的版本号，再从文件导入 Tampermonkey。

可在仓库根目录执行语法检查：

```sh
node --check form-assistant/form-assistant.user.js
```

浏览器回归测试在本目录执行，使用本机 Chrome；可通过环境变量 `PLAYWRIGHT_CHANNEL` 指定其他已安装的 Chromium 浏览器渠道。测试使用隔离的浏览器上下文和模拟油猴存储，不修改日常浏览器中的数据。

覆盖三段入口与全局开关、自定义标签和组件包装、重复 placeholder、动态节点替换、单项规则隔离、旧规则兼容、旧模板回填及恢复。自定义布局用例采用与实际业务页面不同的类名，验证识别不依赖特定项目的 CSS 名称。

`tests/components.test.cjs` 使用真实 Ant Design / React 和 Element Plus / Vue 组件，核对组件的受控数据，而不只检查输入框文字；覆盖日期范围、时间确认、禁用项、级联延迟加载、重名路径、多选、模板、恢复及中途停止。组件库和打包工具仅用于开发测试，不会进入油猴脚本，也不需要业务页面安装它们。

数字回归覆盖 Ant Design 表格中切换核算方式后复用输入框、单位变化时的固定规则与模板隔离、精度补零及真实数值重置，并检查空值、舍入和超出 JavaScript 整数精度的差异不会被误判为相同。

```sh
npm ci
npm run check
npm test
```
