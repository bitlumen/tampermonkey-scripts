# V2EX 纯净阅读助手

版本：**1.0.0**

用于阅读和整理 V2EX 帖子的 Tampermonkey 脚本。合并分页回复，保留正文、附言和常见排版，支持临时移除回复、恢复以及复制。

## 安装

1. 打开 Tampermonkey 管理面板，进入“实用工具”。
2. 使用“从文件导入”，选择本目录的 [v2ex-pure-read.user.js](v2ex-pure-read.user.js)，确认安装。
3. 刷新 V2EX 帖子页面，使用右下角的“纯净阅读”入口。

入口平时贴边，只显示图标；鼠标悬停或键盘聚焦时展开文字，触屏可直接点击图标。脚本匹配 V2EX 及其子域名的 HTTPS 帖子地址 `/t/帖子编号`。

安装只需要一个 `.user.js` 文件，无需 Node.js、构建或运行时依赖。

## 阅读与分页

点击入口打开阅读面板，顶部显示读取状态和保留回复数。

- 正文、作者、时间、附言和回复分别展示，保留链接、图片、列表、引用、表格及代码块。
- 按页顺序合并回复，优先使用网站回复 ID 去重，保留原楼层号。
- 从帖子第一页打开时直接读取当前页面，再请求后续页；从其他页打开时从第一页开始加载。
- 分页逐页读取，已加载内容立即可读。顶部操作栏固定，正文独立滚动。
- “停止加载”取消当前请求；“继续加载”从未完成页继续，已加载内容保留。
- 请求失败、超时、登录跳转或返回内容异常时停止并显示原因；“重试未完成页面”保留已有阅读结果。
- 单次最多读取 200 页，每页请求超时为 15 秒，连续请求间隔至少 350 毫秒。超出页数或单页过大时提示，可通过“查看原帖”继续阅读。

关闭面板会停止加载；再次打开保留本次内容、滚动位置及移除记录，需要时可继续加载。刷新网页后重新读取帖子。

## 整理回复

每条回复右上角的“移除”仅将其从本次阅读和复制内容中排除。顶部显示保留及移除数量。

- “撤销移除”恢复最近一条移除的回复，可连续撤销。
- “恢复全部”恢复本次移除的所有回复。
- 恢复后保持原有排列和楼层号。

这些操作保存在当前标签页内存中，不修改原帖，也不会删除 V2EX 上的回复。关闭面板后仍保留，刷新网页后清空。

## 复制内容

“复制富文本”同时写入 HTML 和纯文本，可粘贴到支持排版的编辑器；“复制纯文本”适合普通文本编辑器。

复制包含标题、作者、时间、正文、附言、原帖链接及当前保留的回复。移除按钮和已移除回复不会包含在结果中。纯文本会保留段落、代码换行，并补充链接及图片地址。

加载未完成时也可以复制，结果会注明仅包含已加载页数。复制使用点击时的内容快照。

富文本复制不可用时尝试纯文本；浏览器拒绝剪贴板访问时，面板提供已选中的纯文本框，可按 `Ctrl+C` / `⌘C` 手动复制。操作结果通过提示条显示。

## 界面操作

- 点击关闭按钮、遮罩空白处或按 `Esc` 关闭面板。
- 打开面板时锁定背景滚动，关闭后恢复原状态和键盘焦点。
- `Tab` / `Shift+Tab` 在面板内切换控件。
- 窄屏自动调整宽度，长代码和表格可在内容区横向滚动。
- 阅读界面使用 Shadow DOM 隔离样式，避免改变原帖排版。

## 支持范围

脚本读取当前网站可访问的帖子页面，分页请求使用当前登录状态。需要登录、网站验证、限流或网络异常时，应先在原帖处理后再重试。

常见正文排版会保留，脚本、事件处理器、表单、iframe 及其他交互嵌入内容不进入阅读面板。链接和图片地址按来源页解析；图片加载仍取决于原始地址是否可访问。

论坛页面结构变化时可能需要调整解析规则。读取期间新增或删除的回复可能影响分页边界；精确内容以原帖为准。

## 开发维护

直接编辑 [v2ex-pure-read.user.js](v2ex-pure-read.user.js)。发布时同步更新脚本头的 `@version`、代码中的 `VERSION`、本说明和 `package.json` / `package-lock.json` 中的版本，再从文件导入 Tampermonkey。

仓库根目录可执行语法检查：

```sh
node --check v2ex-pure-read/v2ex-pure-read.user.js
```

浏览器回归测试使用 Node.js 20+、Playwright 和已安装的 Chrome。在本目录运行：

```sh
npm ci
npm run check
npm test
```

测试使用合成帖子和模拟网络响应，覆盖正文与附言、多页去重、错误重试、停止与继续、移除恢复、剪贴板降级、键盘操作及窄屏布局。测试依赖仅用于开发。
